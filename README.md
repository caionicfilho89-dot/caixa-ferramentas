## ✨ Por que usar a Caixa?

- **🚀 Substitui mais de 20 programas famosos de uma vez:** em vez de baixar iLovePDF, HandBrake, ShareX, Everything, 7-Zip, CCleaner, CPU-Z, Audacity, KeePass e dezenas de outros separadamente, está tudo pronto a um clique.
- **🔎 Barra que responde tudo (`Ctrl+Espaço`):** pergunte em português natural (*"ipva de um carro de 60 mil em SP"*, *"20% de 350"*, *"troco de 100 pra 73,50"*, *"90 dias úteis a partir de hoje"*) e veja a resposta na hora, sem nem precisar abrir janela.
- **🏠 Tela "Hoje" viva:** mostra na abertura o que importa no seu PC agora — espaço livre no Disco C:, arquivos soltos em Downloads, últimos prints com OCR em 1 clique e área de transferência.
- **🔥 Sempre com as Tendências:** acompanha diariamente o que está bombando na comunidade (GitHub Trending, Show HN, Reddit) e traz versões nativas, limpas e em português.
- **🔒 Privacidade total (100% local):** seus PDFs, senhas, fotos e documentos nunca saem do seu computador.

## 💿 Como instalar e usar

### Opção 1 — Instalador do Windows (recomendado)
1. Execute o instalador **`Instalador-CaixaFerramentas.exe`** (ou abra `Caixa.exe` em `%LOCALAPPDATA%\Programs\CaixaFerramentas\Caixa.exe`).
2. Use o atalho da **Área de Trabalho** ou do **Menu Iniciar**, ou chame a barra rápida a qualquer momento com **`Ctrl+Espaço`**.

### Opção 2 — Rodar direto pelo código-fonte (Python 3.10+)
1. Instale a dependência principal da interface:
   ```bash
   pip install -r requirements.txt
   ```
2. Inicie a Caixa:
   ```bash
   pythonw caixa.pyw
   ```
3. Para abrir uma ferramenta específica direto pela linha de comando:
   ```bash
   python caixa.pyw --tool kit-pdf
   ```
